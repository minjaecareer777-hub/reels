# reels

Instagram Reels produced as code: each reel is a folder with a timeline, a renderer and a credits file, so copy, cuts and timing can be changed and re-rendered.

| Reel | What it is | Output |
|---|---|---|
| [`europe-life-reel/`](europe-life-reel/) | "One ordinary Tuesday" in Switzerland and Finland, Korean + Japanese subtitles, soft profile-link ending | `europe-life-reel/out/europe_life_reel.mp4` |
